For open source builders

repo.ing

The market layer for open source.

Launch a market for any public GitHub repository or Hugging Face model on Solana. Every trade pays a fee to the project's builders, even before they show up to claim it.

  • One market per project. Identity follows GitHub's permanent repository ID, so a rename or transfer doesn't create a duplicate.
  • Builders get paid in SOL. A current repo admin verifies with GitHub, binds a wallet, and claims accrued fees.
  • Accounting in public. Payouts, volume, and buyback receipts are published on the Stats page.
Explore markets → Claim builder fees

A community launch does not imply maintainer endorsement, and a repository token gives no ownership of the code, repository, brand, or business. Token trading is risky. Source (AGPL-3.0) · Protocol stats

For friends, clubs, and communities

Ohiyo

Group chat that's actually yours.

A free, open source group chat: text, voice, video, screen share, and watch parties. Sign up with a username and password, no email needed, and send your friends an invite link.

  • A lock for private chats. Turn it on in a DM or group chat and messages are encrypted on your device; one-to-one chats use the Signal Protocol.
  • No ads, no paid tier. Themes, custom emoji, and GIF avatars are part of the app.
  • Leave whenever you like. Rebuild a Discord server from its template, or self-host: one server program and one database file.
Open Ohiyo → Desktop apps

Public beta. The lock is opt-in, and the encryption has not been externally audited yet; the threat model spells out what is and isn't protected. Threat model · Source (AGPL-3.0)

For AI agent developers

wmcp.sh

Turn any URL into agent-callable MCP tools.

A hosted, spec-compliant MCP server. Point Claude Code, Cursor, Codex, or any MCP client at a URL and your agent can read prices, list variants, or call an API on a site that ships no MCP server of its own.

  • One endpoint, not one server per site. Shopify, JSON-LD, OpenAPI, and provider adapters run first; an LLM fallback produces best-effort tools.
  • One line of config. Add the URL to your MCP client, or call the REST API directly.
  • Free to try. Discovery is 100 reads a day with no signup; live tool execution starts at $39/mo.

The engineering

Korg

Prove what your AI agent did.

A separate project, and the clearest look at how I build: a tamper-evident, SHA-256-chained ledger for AI agents. Edit one recorded event and the verifier names it. No trust in the producer, no blockchain.

  • Three independent verifiers. Rust, Python, and JavaScript implementations, differentially fuzzed against each other.
  • Cross-vendor format. Adapters ingest Claude Code, OpenAI Codex CLI, and Grok Heavy traces into one korg-ledger@v1 spec.
  • Limits written down. v1 targets local, single-user workspaces, and agents must be told to log.
